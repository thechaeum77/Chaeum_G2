# 채움 G2

Google Search Console에서 URL 검사와 색인 생성 요청을 빠르게 처리하기 위한 크롬 확장 프로그램입니다.

## 코드 기준 현재 기능
- Search Console 페이지(`https://search.google.com/search-console*`)에서만 동작
- 우측 패널/토글 버튼을 띄워 검사 대상 URL 입력 지원
- 현재 페이지의 `resource_id`(선택된 속성) 기준으로 검사 흐름 실행
- 입력한 URL로 URL 검사 화면 이동 후 자동 입력/실행
- 미색인 상태 감지 시 색인 생성 요청 버튼 위치 안내(수동 클릭)
- RSS 최신 글 불러오기(`.../rss`, `.../feed`, `.../atom.xml` 후보 순회)
- RSS 결과는 최신순으로 정렬되어 첫 10개 기본 표시
- RSS 목록 하단 `이전/다음` 버튼으로 10개씩 페이지 이동
- 마지막 페이지에서 `다음` 클릭 시 RSS 이전 포스팅을 추가 조회 시도
- RSS 결과는 속성별로 최대 200개까지 로컬 캐시

## 사용 흐름
1. Search Console 속성 화면에서 우측 하단 `채움 G2 열기` 버튼 클릭
2. 검사할 URL 입력 (예: `https://example.com/post/123`)
3. `이 포스팅 검사` 클릭
4. 검사 결과가 미색인이면 색인 생성 요청 버튼을 수동으로 클릭
5. `RSS 최신 글 불러오기` 후 첫 페이지(최신 10개)에서 확인, 하단 `이전/다음`으로 페이지 이동
6. 원하는 포스팅 선택 시 URL이 채워지고 `이 포스팅 검사` 버튼 위치로 바로 이동

## 참고
- 현재 코드에는 별도 옵션 페이지/블로그 목록 저장 UI가 없습니다.
- Search Console UI 변경 시 자동 감지 로직 보정이 필요할 수 있습니다.
